2. 게시글

비회원은 글과 댓글을 읽을 수 있습니다. 프런트엔드는 받은 목록에서 제목·본문·작성자 검색, 최신순·추천순·조회순 정렬과 페이지 나누기를 제공합니다. 게시글 상세의 본문 발췌는 마크다운에서 텍스트를 추출해 브라우저에서 표시합니다.

메서드 및 경로권한요청 및 응답
GET /posts공개200 · 게시글 배열
GET /posts/{id}공개200 · 게시글 객체. 삭제된 글 및 없는 글은 404
POST /posts회원{title, content, category?} → 201 {postId}. 제목 최대 255자, 본문 최대 10,000자. 생략한 카테고리는 자유
PUT /posts/{id}작성자{title, content, category?} → 200 · 수정된 게시글 객체
DELETE /posts/{id}작성자204 · 소프트 삭제
POST /posts/{id}/views공개200 · 증가 후 조회수
PUT / DELETE /posts/{id}/like회원200 {likes, likedByMe}. 동일 상태로 재요청 가능

게시글 객체 필드 id, title, category, content, author, authorId, createdAt, likes, comments, views, likedByMe.

3. 댓글

메서드 및 경로권한요청 및 응답
GET /posts/{id}/comments공개200 · 작성 순서 댓글 배열. 삭제된 댓글 제외
POST /posts/{id}/comments회원{content} → 201 · 새 댓글. 최대 2,000자
PUT /posts/{id}/comments/{commentId}작성자{content} → 200 · 수정된 댓글
DELETE /posts/{id}/comments/{commentId}작성자204 · 소프트 삭제

댓글 객체 필드 id, postId, author, authorId, content, createdAt. 다른 글에 속한 댓글을 지정하면 404를 반환합니다.

PUT /profile회원{nickname, bio, affiliation, techStack} → 200 · 저장된 프로필. 기술 항목은 최대 12개

프로필 객체 필드 userId, nickname, email, bio, affiliation, techStack, profileImage.

5. 채팅

메서드 및 경로권한요청 및 응답
GET /chat/rooms공개200 · 요청자가 열 수 있는 방 배열
POST /chat/rooms회원{title, description, category, isPrivate, allowGuest} → 201 · 새 채팅방. 비공개 방의 비회원 열람은 항상 비활성
GET /chat/rooms/{id}방 접근 권한200 · 채팅방 객체
GET /chat/rooms/{id}/messages방 접근 권한선택적 ?before={messageId} → 200 · 최신 최대 50개, 시간 오름차순. 화면은 2.5초 간격으로 최신 메시지를 조회
POST /chat/rooms/{id}/messages회원과 방 접근 권한{content} → 201 · 새 메시지. 최대 2,000자. 공개 방은 첫 메시지 전송 시 가입
DELETE /chat/rooms/{id}/messages/{messageId}메시지 작성자204 · 소프트 삭제. 메시지는 isDeleted: true와 빈 본문으로 반환
POST /chat/rooms/{id}/invites비공개 방장{minutes} → 201 {token, expiresAt}. 유효 기간 1~10,080분, 신규 입장 1회
POST /chat/invites/{token}/accept회원200 · 가입한 방. 알 수 없는 토큰 404, 만료 또는 소진된 토큰 410. 기존 참가자는 재수락 가능

방 객체 필드 id, title, description, category, isPrivate, allowGuest, participants, ownerId, ownerNickname. 메시지 객체 필드 id, senderId, senderNickname, content, createdAt, isDeleted.

공개 방의 비회원 열람은 방 설정에 따릅니다. 비공개 방은 가입한 계정만 조회 및 전송할 수 있습니다.

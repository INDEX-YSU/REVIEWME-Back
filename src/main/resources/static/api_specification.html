1. 이메일 회원가입 / 로그인

POST/auth/signup인증 불필요

이메일/비밀번호 기반 회원가입
Request Body 
{
  "email": "user@example.com",
  "password": "P@ssw0rd123",
  "nickname": "ivor"
}
Response 201 
{
  "success": true,
  "data": {
    "userId": "u_1029",
    "email": "user@example.com",
    "nickname": "ivor",
    "role": "USER"
  }
}
에러409 EMAIL_ALREADY_EXISTS · 400 INVALID_REQUEST(비밀번호 정책 위반)

POST/auth/login인증 불필요

이메일/비밀번호 로그인, Access Token 및 HttpOnly Refresh Token 쿠키 발급
Request Body 
{ "email": "user@example.com", "password": "P@ssw0rd123" }
Response 200 
{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOi...",
    "expiresIn": 3600,
    "user": { "userId": "u_1029", "nickname": "ivor", "role": "USER" }
  }
}
Set-CookierefreshToken={token}; HttpOnly; SameSite=Strict; Path=/api/v1/auth
운영 환경에서는 Secure 속성 포함
에러401 INVALID_CREDENTIALS

POST/auth/refreshRefresh Token 필요

HttpOnly 쿠키의 Refresh Token으로 Access Token 재발급 및 Refresh Token 회전
CookierefreshToken={token} (Request Body 없음)
Response 200
{ "success": true, "data": { "accessToken": "eyJ...", "expiresIn": 3600 } }
Set-Cookie회전된 새 Refresh Token 쿠키
에러401 INVALID_REFRESH_TOKEN

POST/auth/logout인증 필요

현재 Refresh Token 무효화
CookierefreshToken={token}
Response 200
{ "success": true, "message": "로그아웃 되었습니다." }
Set-CookieRefresh Token 쿠키 즉시 만료

2. GitHub 로그인 / 연동

GET/auth/github인증 불필요

GitHub OAuth 인가 페이지로 리다이렉트
QueryredirectUri (선택, 인가 완료 후 프론트 리다이렉트 경로)
Response302 Redirect → GitHub OAuth authorize URL

GET/auth/github/callback인증 불필요

GitHub 인가 코드 콜백 처리 → 신규면 회원가입, 기존이면 로그인 처리 후 토큰 발급
Querycode, state
Response 200
{
  "success": true,
  "data": {
    "accessToken": "eyJ...",
    "isNewUser": false,
    "user": { "userId": "u_2044", "nickname": "ivor-dev", "githubLogin": "ivor" }
  }
}
Set-CookieHttpOnly Refresh Token 쿠키

POST/auth/github/link인증 필요

기존 로그인 계정에 GitHub 계정 연동 (OAuth code 전달)
Request Body
{ "code": "gho_authcode..." }
Response 200
{ "success": true, "data": { "githubLogin": "ivor", "linkedAt": "2026-07-10T12:00:00Z" } }
에러409 ALREADY_LINKED_TO_ANOTHER_ACCOUNT

DELETE/auth/github/link인증 필요

GitHub 연동 해제
Response 200
{ "success": true, "message": "GitHub 연동이 해제되었습니다." }

4. Guest 권한 처리

POST/auth/guest인증 불필요

비로그인 사용자를 위한 임시 Guest 세션 발급 (읽기 전용 토큰)
Response 200
{
  "success": true,
  "data": { "guestToken": "eyJ...", "role": "GUEST", "expiresIn": 86400 }
}
Guest 권한 정책: 게시글/댓글 조회, 조회수 증가 API만 허용됩니다.
작성 · 수정 · 삭제 · 추천 · 채팅 관련 API는 403 FORBIDDEN(GUEST_NOT_ALLOWED)으로 응답합니다.
Guest가 회원가입/로그인 시 기존 Guest 활동 이력(조회 기록 등)은 이전되지 않습니다.

14. WebSocket 채팅

WSwss://api.example.com/v1/ws/chats/{roomId}?token={accessToken}

채팅방 실시간 메시지 송수신용 WebSocket 연결. 연결 시 Access Token으로 인증하며, 방 멤버가 아니면 연결 즉시 종료(4403)됩니다.
Client → Server 
// 메시지 전송
{ "type": "MESSAGE", "content": "안녕하세요!" }

// 입력 중 표시
{ "type": "TYPING" }
Server → Client 
// 새 메시지 브로드캐스트
{
  "type": "MESSAGE",
  "data": {
    "messageId": "m_5002", "roomId": "r_701",
    "senderId": "u_1029", "nickname": "ivor",
    "content": "안녕하세요!", "sentAt": "2026-07-10T10:01:00Z"
  }
